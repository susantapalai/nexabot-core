# NexaBot 🤖
### AI-powered WhatsApp chatbot for local businesses

Built in 3 days. Real product. Real WhatsApp replies.

## Demo
Customer asks on WhatsApp → AI replies in seconds
No human needed. Powered by Gemini 2.5 Flash.

## Tech Stack
- Java 17 + Spring Boot 3.5.14
- Google Gemini 2.5 Flash
- PostgreSQL
- Twilio WhatsApp API
- Spring WebFlux
